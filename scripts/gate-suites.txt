# Exact-tree gate suite manifest (read by scripts/gate.sh).
#
# Every integration test file (crates/<crate>/tests/<name>.rs) must appear
# here exactly once, by `<crate>/<name>`; `scripts/gate.sh --check` fails on a
# file that is missing or an entry that no longer exists.
#
# Line format: <lane> <name> [cargo test arguments]
#   serial-pg  run one at a time against a PostgreSQL 17 container on port
#              55432, with DELTAFORGE_IT_PG_DSN set
#   serial     run one at a time (timing-sensitive or fixed-port suites)
#   parallel   run concurrently (each suite starts its own containers)
#   release    run concurrently, by the release tier only
#              (`scripts/gate.sh --release`)
#   workspace  no ignored tests; covered by the `cargo test --workspace` step
#   excluded   not run by either tier; the rest of the line must give the
#              reason
# Without an explicit `--`, gate.sh appends
# `-- --include-ignored --test-threads=1`.
